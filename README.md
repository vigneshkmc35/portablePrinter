# Portable Billing App

A modern, high-efficiency billing application for retail shop owners. 

## Features
- **Fast Billing**: Add items to cart with a single tap.
- **Quick Create**: Add new inventory items on-the-fly from the dashboard search.
- **Partial Quantities**: Support for fractions (0.25, 0.5, 0.75) for loose items like grains.
- **Theme Support**: Personalized app colors with dynamic card accents.
- **Bluetooth Printing**: Integration with portable ESC/POS thermal printers.

## Tech Stack
- **Kotlin** & **Jetpack Compose**
- **Room Database** for local storage
- **Material Design 3**
